## ⚠ 給實作者（Claude Code）的硬性要求

1. **開工前先把原型跑起來、逐頁點過一輪**，包含：日常頁拖曳把手、左滑分類卡、切分頁、開記一筆面板、

2. **UI、圖示、動畫、間距、圓角、陰影、顏色一律照原型復刻**，不要「用自己的判斷優化」。
   任何你覺得該改的地方，先做出貼近原型的版本，再另外提出建議。
3. **不得替換元件庫的預設樣式**：不要用 Material／Ant／Bootstrap 的預設按鈕、卡片、彈窗外觀。
   本設計的實體感陰影（`0 3px 0`）、饅頭幾何、毛玻璃分頁列都是刻意的，不可用一般 `box-shadow` 模糊陰影替代。
4. **動畫不是加分項，是規格**。第 10 節列的 30 條全部要有；標「待補」的是原型還沒做但**必須**做出來的。
   缺一條就算未完成。
5. **手勢要跟手**，不能只做「點一下切換」：月曆把手、分類卡左滑、邀請面板下滑，
   三者都必須即時跟隨手指、有阻尼、放手依距離與速度吸附。
6. **完成後逐條對照第 0 節清單與第 10 節動畫表自我驗收**，並回報哪幾條做了、哪幾條有落差與原因。
7. 與本文件衝突時以原型為準；原型沒有的行為以本文件為準；兩者都沒有的，先問再做。

## 1. 產品定義

- 兩人（我／老婆）共用**同一份**帳本，資料存在 Google Sheets。
- 主幣別 **CAD**。非 CAD 的紀錄**不做匯率換算**，由記帳人手填「實際扣款 CAD」。
- 所有統計一律使用「實扣 CAD」欄位計算，因此帳目與信用卡帳單一致。
- 介面語言：繁體中文（英文僅作裝飾性副標）。

- 分類子頁右上「新增分類」：同款漸層、`38×38`、圓角 `14px`，只有 ＋ 圖示。

底部分頁的饅頭**沒有腳**；標題與登入頁的大饅頭有兩隻小腳（`#9484CE`）。
空狀態用灰階版（`#DEDCE6` / `#CDCBD6` / 眼睛 `#8D89A1`），嘴改為向上弧線。

## 4. 日常頁

版面自上而下：**月份導覽（固定）→ 收支三卡（可收起）→ 月曆（可收起）→ 把手 → 日期標題（固定）→ 明細（獨立捲動）**
右下角另有懸浮 ＋（不隨捲動，只在這一頁）。

- 外層容器不捲動（`overflow:hidden`），只有明細區有自己的 scroll。
- 月份導覽：`‹ 2026年9月 ▾ / September 2026 ›`，白色圓形箭頭鍵切換月份，跨年要正確進退。
  - **標題可點**：展開年月快速選擇器（MOTION 33、34）―四個年份 pill（可用 `‹ ›` 翻年）+ 12 個月方格 + 「收起」；
    展開時收支三卡與月曆先收起，選完即收合並播方向性滑入。
  - 選到的月份天數較少時，選中日自動夾到該月最後一天（不可出現 2/31）。
- 收支三卡：收入（綠底）、支出（橘底）、結餘（深色底，副標顯示結算期間）。
  三個數字都是**整月合計**（不隨選中日變），且都要 count-up（MOTION 31）。
- 月曆
  - 星期列跟著「週起始」設定變動（週一時為 一二三四五六日，且首格空白數同步位移）。
  - 週末（六、日）星期字為 `#B85F42`。
  - 每格：日期數字 + 當天支出（≥1000 顯示 `$1.2k`）+ 有收入時下方一條 `#DDA6D0` 短線。
  - 格底色濃度依當天支出／當月最大值：`rgba(183,166,229, .14 + ratio*.44)`。
  - 選中框是**一塊獨立滑塊**（MOTION 6），不是格子自己的樣式；今天的日期數字用深色。
  - **左右滑可換月**（MOTION 7），但必須先超過 10px 橪向位移才接管，不可影響點日期。
- 把手（**必做手勢**）
  - 往上滑：月曆區跟手收起（`max-height 460→0`，opacity 同步），明細補滿。
  - 往下拉：月曆跟手回來。
  - 放手判定：位移 >138px 或速度 >0.4px/ms 吸附到目標；否則彈回。位移 <6px 視為點擊，直接切換。
  - 拖曳中關閉 transition；`touch-action:none`。
  - 提示文字隨狀態變：「往上滑看更多明細」／「往下拉看月曆」。
  - 收起／展開後**明細的 scroll 位置不重置**。
- 日期標題列（固定）：`9月6日 · 週日` + 当日總額（也要 count-up，點不同日期跑 480ms）+ 分隔線。
- 明細列表
  - 每筆：分類圖示（36×36 圓角 13，底色為分類 tint）、分類 pill、子分類、時間、備註（過長 ellipsis）、金額、原幣別、記帳人頭像。
  - 支出金額前綴 `-` 深色，收入 `+` 綠色；下方小字顯示原幣別（CAD 顯示 `CAD`，否則 `1,280 TWD`）。
  - 記帳人頭像：我 `#B7A6E5`、老婆 `#DDA6D0`；配置頁關掉「每筆顯示記帳人」時隱藏（opacity 0，保留版位）。
  - **每筆可點進編輯**（見第 5 節）。
  - 依時間升冪排序。空狀態顯示灰饅頭 +「這天還沒有紀錄」。

## 5. 記一筆／編輯面板

同一個面板兩種模式：從右下懸浮 ＋ 進入是**新增**，點明細任一筆進入是**編輯**（欄位帶入原值）。

- 上滑進場；取消、儲存、**把手下滑**三種方式都是下滑離場（MOTION 35）。
- 頂部：支出／收入分段控制（**獨立滑塊**，MOTION 36）+ 右上圖示鍵；下一行小字標示「記一筆」∕「編輯這筆」。
  - 新增模式：只有 `✕` 關閉鍵（`38×38` 圓形）。
  - 編輯模式：左邊多一顆垃圾桶鍵（同尺寸、底 `rgba(217,112,92,.12)`、圖示 `#B4523F`）。
- 收入模式的子分類換成 薪資、退稅、獎金、其他。
- 金額區可點擇焦：金額本身 / 實扣 CAD 兩個欄位共用同一組數字鍵盤，選中欄位有紫色外框。
- 幣別 CAD / TWD / USD。**非 CAD 時**才出現「實際扣款 CAD」欄位，提示文字：
  「非 CAD：請填銀行實際扣款的 CAD 金額（不用匯率換算）」。CAD 時顯示「主幣別 CAD · 直接記錄」。
- 主分類 chip（含圖示）／子分類 chip，各自帶一顆虛線「＋ 新增」，就地建立後立即選中。
- **日期欄可點**（MOTION 38）：新增時預設為月曆上選中那天，編輯時帶入原紀錄日期。
  點開就地展開小月曆：`‹ ›` 換月（跨年正確、跳到天數較少的月份時自動夾到月底）、
  選中日 `#EDE9FA` 底 + `inset 0 0 0 2px #B7A6E5` 外框、每格 `min-height:34px`、
  下方「今天」（淡紫底深紫字）與「收起」兩鍵；選日後即收合。日期欄本身在展開時套紫色外框、`▾` 轉 180°。
  儲存時寫入的是這裡選定的日期，不是月曆上的選中日。
- 記帳人可切我／妻。
- **備註欄**（可不填）：白卡輸入欄，placeholder「例：Costco 週採買」；編輯模式帶入原備註；
  留空時新增的紀錄不顯示備註（原型以「剛剛新增」代替，實作應存空字串）。
- 數字鍵盤 3×4（1-9、`.`、0、⌫），右側儲存鍵跨四列：
  - `⌫` 鍵用**淡紫底 `#EDE9FA` + 深紫圖示 `#6B57B8`**（不可用灰色）。
  - 儲存鍵只有**一個白色大勾號**（`30×30`），無文字；新增與編輯都一樣。
  - 小數最多兩位、總長 9 字。所有鍵都有按壓回饋（MOTION 3）。
- 儲存後：面板下滑、跳回日常頁、新紀錄出現在明細最前並播放進場動畫。金額為 0 時不寫入。
- 編輯模式按垃圾桶 → **先跳確認視窗**（MOTION 37）：顯示該筆的分類·子分類與金額、
  說明「刪除後無法復原，對方的手機也會同步移除」，取消／刪除兩鈕。

## 6. 統計頁

- 週／月／年三個維度（分段控制，**白色獨立滑塊**，MOTION 32）。
- 結餘總覽卡：期間標籤（月結日非 1 號時顯示如 `9/15 – 10/14`）、與上期增減 pill（▲綠／▼橘）、大數字、饅頭、收入／支出雙欄與比例條。
  **結餘、收入、支出三個數字都要 count-up**（進頁從 0、換維度從前一值，MOTION 11）。
- 趨勢：SVG 折線，支出實線 `#9484CE`、收入虛線 `#DDA6D0`、支出下方淡色面積、最後一點加大。X 軸標籤依維度變（W27…／4月…／2023…）。
- 預算使用：每個主分類一條，`已花 / 預算`，超支轉 `#E08A72` 並顯示「超支 $X」，>85% 轉 `#F2C97A`，否則分類色。週維度 ×0.25、年維度 ×11.4。
- 進頁時預算條依序填充（見 MOTION 8）。

## 7. 配置頁

1. **帳本成員**：我（擁有者）、老婆（可編輯 · 最後同步時間）、邀請成員 → 彈邀請面板（見第 8.2 節）。
2. **分類與預算**（一列摘要，點進獨立子頁）：
   - 摘要列：五個分類圖示疊在一起 + 「編輯分類與月預算」+ 副標「N 個分類 · 月額度 $X」+ `›`。
   - 子頁自右滑入（MOTION 14），左上 `‹` 返回。**標題列與提示行固定，只有分類卡清單捲動。**
   - 右上「新增分類」圖示鍵 → 新卡**插入清單最上方**，名稱欄自動進入編輯，**不**自動展開圖示選擇器；
     預設圖示 bag、預算 150、一個「其他」子分類，配色依序循環六組紫色系。
   - 每張分類卡：
     - 點左側圖示 → 展開 15 個圖示選擇器（每顆 44×44，選中有外框）；換完即時同步明細∕預算條∕記帳選單。
     - 點分類名稱 → 就地變輸入欄，✓ 確認（重名或空白則取消）。
     - 點金額 pill → 就地變輸入欄，✓ 存、✕ 取消（皆 44×44 圓形）。
     - 子分類 chip 點一下刪除（至少留一個），「＋ 子分類」就地新增（✓ 確認）。
     - **左滑露出刪除鍵**（MOTION 15）→ 確認視窗（MOTION 16）顯示「已用在 N 筆紀錄」，

## 8. 登入與邀請

「登入」「邀請面板」「接受邀請」是**同一條流程的三段**，不是三個獨立功能。
原型上方的三個切換（主程式／登入／接受邀請）只是方便分別檢視這三個畫面。

### 8.1 完整路徑

**建立者（我）**
1. 開啟 App → 未登入 → **登入頁** → Google 登入（只要求 `drive.file`）。
2. App 在我的雲端硬碟建立「加拿大共用記帳」，寫入四張工作表 → 進**主程式**。
3. 配置頁 →「邀請成員」→ **邀請面板**，產生連結。

**被邀請者（老婆）**
4. 收到連結 → 在她手機開啟 `https://<app>/join?sid=<spreadsheetId>&t=<簽章>`。
5. 落地在**接受邀請頁**（先看到邀請卡與權限說明，尚未寫入任何東西）。
6. 按「用 Google 登入並加入」：
   - **未登入** → 走 Google redirect 授權 → 回程帶回 `sid` → 自動完成加入 → 進主程式。
   - **已登入過** → 跳過授權，直接完成加入 → 進主程式。
   - **已是成員** → 不重複加入，直接進主程式（顯示「你已在這本帳裡」）。
7. 加入時後端動作：`drive.permissions.create`（role `writer`、type `user`）+ 成員寫進配置頁成員區塊。
8. 之後雙方讀寫同一張紀錄頁。

**例外分支（都要實作）**
- 連結過期（>7 天）或簽章不符 → 接受邀請頁改顯示「這個邀請已失效，請對方重新產生」，CTA 變成「回首頁」。
- 她按「先看看，暫不加入」→ 進唯讀試用狀態，不寫入任何資料，配置頁顯示「尚未加入帳本」。
- 建立者未登入就打開 join 連結（同一支手機測試）→ 一律先走登入，再回到接受邀請頁。

### 8.2 邀請面板（配置頁 → 邀請成員）

- 由底部上滑進場；**把手可往下拖曳關閉**（位移 >110px 或速度 >0.4px/ms 吸附關閉，否則彈回），
  另有「關閉」文字鍵。
- 內容：邀請連結預覽（過長 ellipsis）、主 CTA「複製邀請連結」、
  次要兩鍵「用訊息傳送」「顯示 QR Code」、下方三條說明、最下方「預覽她點開後看到的畫面 ›」。
- **複製邀請連結**：寫入剪貼簿（`navigator.clipboard.writeText`），按鈕文字換成「已複製連結」
  且底色轉綠 `#3E7F63`，2.2 秒後復原。
- **用訊息傳送**：呼叫 `navigator.share({ url })` 開啟系統原生分享單（iMessage／LINE／WhatsApp…）；
  不支援 Web Share API 時退回複製連結並提示。
- **顯示 QR Code**：就地展開 QR（內容與連結完全相同），掃描後落地在**接受邀請頁**。
  原型上的 QR 是示意圖，實作請用 QR 產生器（例如 `qrcode` 套件）依真實連結產生。
- **預覽她點開後看到的畫面**：僅供建立者確認，導到接受邀請頁的預覽狀態，不觸發任何寫入。

### 8.3 畫面規格

- 登入頁：大饅頭（有腳）+ 標語「兩人一本，加拿大生活記帳」+ Google 登入按鈕（白底、四色圓點）
  + 權限說明小字「只會取得建立與編輯這一份試算表的權限」。
- 接受邀請頁：兩隻饅頭的邀請卡（邀請人名稱、帳本名稱、權限 pill）、
  「加入後會發生的事」三條、主 CTA「用 Google 登入並加入」、次要「先看看，暫不加入」。
- 兩頁都從狀態列下方開始（`top: env(safe-area-inset-top)`，原型為 52px）、`overflow:hidden`。

## 9. Google Sheets 結構

**紀錄頁**：`日期 | 主分類 | 子分類 | 金額 | 幣別 | 實扣 CAD | 記帳人 | 備註`
每筆新增 append 一列。實扣 CAD 為手填，無公式。

**配置頁**：`主分類 | 子分類 | 月預算 CAD | 排序 | 啟用`
App 配置頁編輯後寫回；`啟用=FALSE` 的分類不出現在記帳選單。
（實作時另需一欄 `圖示` 存 icon key。）

**年報表頁**：分類 × 十二個月交叉表，`SUMIFS` 取自紀錄頁，末列與末欄為公式。

**圖表頁**：`月份 | 支出 | 收入 | 結餘`，綁 Sheets 原生折線圖。

同步要求：
- 寫入期間顯示同步中狀態（MOTION 11）；失敗要可重試，且不可產生重複列。
- 對方新增時推播通知並在 App 顯示 toast（MOTION 10）。

## 11. 容易漏掉的細節（請特別確認）

1. 統計頁的三個維度切換時，**預算條倍率**（週 ×0.25、年 ×11.4）與期間標籤都要跟著換。
2. 月結日不是 1 號時，日常頁結餘卡副標與統計頁期間標籤都要顯示區間。
3. 週起始設為週一時，月曆首格空白數要一起位移，不只是星期列的字。
4. 明細金額用「實扣 CAD」，但小字仍顯示原幣金額與幣別。
5. 新建分類要同時給圖示、四色配色、預設預算 150、一個同名子分類。
6. 子分類至少保留一個，不可刪成空。
7. 記帳人開關關閉時是隱藏頭像（保留版位），不是移除元素。

## 12. 平台與 PWA

交付形式：**PWA**，手機優先，主要驗證機為 iPhone；Android Chrome 需可正常使用。

### 12.1 基本設定
- `manifest.json`：`display: "standalone"`、`orientation: "portrait"`、
  `theme_color: "#FFF6EC"`、`background_color: "#FFF6EC"`、
  圖示 192／512／maskable 512（紫饅頭）。
- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`
- `apple-mobile-web-app-capable`、`apple-mobile-web-app-status-bar-style="default"`、
  `apple-touch-icon`（180px）、iOS 啟動畫面（可選）。
- Service Worker：App shell 與 15 個圖示走 cache-first；Sheets 資料走 network-first
  並保留最後一次成功結果，離線時顯示快取資料 + 「離線中」狀態（沿用同步狀態那顆點的版位）。
- 離線時新增的紀錄先寫入本地佇列，回線後依序 append，並確保不重複寫入。

### 12.2 安全區與尺寸
- 底部分頁列與 ＋ 按鈕：`padding-bottom: max(30px, env(safe-area-inset-bottom))`。
- 頂部：原型的 `52px` 狀態列區＝ `env(safe-area-inset-top)`，登入頁與邀請頁從該高度下方開始。
- 全部彈性寬度，不寫死寬度；同一版面要能在 iPhone SE（375×667）到 15 Pro Max（430×932）都不破版。
- 高度較小的機型（≤667）優先壓縮月曆格高度與卡片間距，不動字級下限。

### 12.3 iOS 特別注意
- 不用 `100vh`，改 `100dvh`（或 `-webkit-fill-available`），否則工具列會截掉底部。
- `overscroll-behavior: none` 於 body，避免整頁橡皮筋；明細區保留自身彈性捲動
  （`-webkit-overflow-scrolling: touch`）。
- 把手的拖曳用 Pointer Events，並在容器上 `touch-action: none`，
  同時擋掉 iOS 的下拉重整手勢與雙指縮放（`user-scalable=no` 不可靠，改用 `touch-action`）。
- 輸入欄位字級 ≥16px，否則 Safari 會自動放大整頁。
- Google 登入不可用彈出視窗（standalone PWA 會被擋），改用 redirect flow，
  回程 URL 需在 standalone 模式下也能回到 App。
- `-webkit-tap-highlight-color: transparent`，並自行提供按壓態（見 MOTION 2）。
- iOS 不支援 Web Push 於非 standalone 情境；「對方記帳時通知我」在 iOS 需
  加到主畫面後才可用，設定列要在不支援時顯示原因而非直接失敗。

### 12.4 Android
- 深色模式先不做（介面固定亮色），但需設定 `color-scheme: light` 避免系統反轉。
- 系統返回鍵：面板／選擇器開啟時攔截返回鍵先關閉當層，不直接離開 App。

## 14. 資料層寫法建議

技術棧：PWA（建議 React + TypeScript + Vite + vite-plugin-pwa）。以下為建議實作，不是硬規定，
但**行為契約**（欄位、id、寫入方式、離線佇列、衝突處理）必須照做。

### 14.1 架構分層

```
ui/            畫面元件，只讀 store，不直接碰 Google API
store/         單一狀態來源（Zustand 或 Redux Toolkit）
repo/          ledgerRepo：對 UI 提供 add/update/delete/list，內部決定走本地或遠端
sheets/        Google Sheets API 封裝（values.append / values.get / batchUpdate）
auth/          Google OAuth（redirect flow）、token 保存與續期
sync/          離線佇列、輪詢、衝突處理
```

UI 只依賴 `repo`。換掉 Sheets（例如改 Firestore）時只動 `sheets/` 與 `sync/`。

### 14.2 認證

- OAuth 2.0 授權碼流程 + PKCE，**redirect 模式**（standalone PWA 擋 popup）。
- scope 只要 `https://www.googleapis.com/auth/drive.file`
  （只能存取本 App 建立的檔案，不需要整個雲端硬碟權限）+ `openid email profile`。
- access token 存記憶體，refresh token 存 `IndexedDB`（不要放 localStorage）。
- 過期前 5 分鐘自動續期；續期失敗導回登入頁但保留本地資料。

### 14.3 帳本識別

- 建立帳本 = 在使用者硬碟建立一份 Spreadsheet，寫入四張工作表與標頭列。
- `spreadsheetId` 存本地，並寫進 Sheet 的「配置頁」一個隱藏區塊當自我描述。
- 邀請連結：`https://<app>/join?sid=<spreadsheetId>&t=<簽章>`。
  接受方登入後：`drive.permissions.create`（role: writer, type: user）→ 把成員寫進成員區塊。
- 簽章用來防止連結被亂猜；過期時間建議 7 天。

### 14.4 資料模型

紀錄頁一列對應一筆：

```ts
type Txn = {
  id: string;          // uuid v4，App 產生，存在 A 欄之外的隱藏欄（見下）
  date: string;        // YYYY-MM-DD
  main: string;        // 主分類名稱；收入用 "收入"
  sub: string;
  amount: number;      // 原幣金額
  currency: 'CAD' | 'TWD' | 'USD';
  actualCad: number;   // 實際扣款 CAD；CAD 時等於 amount
  by: '我' | '妻';
  note: string;
  updatedAt: string;   // ISO，衝突判定用
};
```

- **實務建議**：紀錄頁除了原型上那 8 個可見欄，另加兩個欄位 `id`、`updatedAt`（可放在 I、J 欄）。
  沒有 id 就無法可靠地更新或刪除某一列（列號會因排序、插入而位移）。
- 所有統計一律用 `actualCad`；`amount`／`currency` 只用於顯示。
- 分類設定同理，配置頁加 `icon`（Fluent key）與 `id` 欄。

### 14.5 讀寫

- 新增：`spreadsheets.values.append`（`valueInputOption: 'RAW'`，
  `insertDataOption: 'INSERT_ROWS'`）。**一次一列，不要先讀再寫整表。**
- 更新／刪除：先以 id 找到列號（本地索引），再 `values.update`；
  刪除建議走軟刪除（加 `deleted` 標記）或 `batchUpdate` 的 `deleteDimension`。
- 讀取：啟動時抓當月 + 前一月，其餘按需分頁抓（`A1` range 帶月份區間）。
  年報表與圖表頁由 Sheets 公式維護，App 不需重算，統計頁若嫌慢可直接讀年報表頁。
- 所有寫入操作要 exponential backoff 重試（429／5xx），最多 5 次。

### 14.6 離線與同步

- 本地快取：IndexedDB（建議 Dexie），一張 `txns`、一張 `categories`、一張 `outbox`。
- 樂觀更新：UI 立即顯示，同時寫 `outbox`；成功後標記 synced。
- **去重**：`append` 前檢查 `outbox` 該筆是否已有 `serverRowId`；
  重試時帶同一個 `id`，回線後先讀取遠端是否已存在該 id 再決定是否 append。
- 拉取策略：App 回到前景、下拉重整、以及每 60 秒輪詢一次（僅前景）。
  Sheets 沒有即時推送，如需更即時可加一個 Apps Script 觸發器發 Web Push。
- 衝突：同一 id 以 `updatedAt` 較新者勝；兩人同時新增不同筆不會衝突（append 天然安全）。
- 狀態機對應 UI：`idle → syncing → synced | offline | error`，
  直接餵給同步狀態那顆點（MOTION 11）。

### 14.7 效能與注意事項

- 月曆的每日合計、統計的分類合計都在本地由 `txns` 計算並 memo，不要每次都打 API。
- Sheets API 有配額（每分鐘每使用者約 60 次讀寫），輪詢與批次要節制。
- 金額用整數分（cents）在內部運算，顯示時再除 100，避免浮點誤差。
- 時區固定用使用者本地時區產生 `YYYY-MM-DD`，不要用 UTC，否則跨日會錯一天。
- 分類改名時，紀錄頁已寫入的字串不要回頭批次改；改用 id 關聯，或明確告知使用者會影響歷史資料。
