# 需要手動驗證的項目

自 2026-09-09 起，開發以功能進度為主：**只寫單元測試**，互動／瀏覽器層面不好自動化的
就跳過，改列在這裡讓擁有者手動驗。

每一列都寫清楚「怎麼操作」與「該看到什麼」，才不會變成一句無法執行的空話。

狀態：`待驗` / `通過` / `有問題`

## Plan 03 已自動化的部分（不需手動）

手勢引擎的門檻、跟手比例、阻尼、點擊判定、`touch-action` 都有真實瀏覽器測試
（`e2e/gesture.spec.ts`，8 條）。上面 M1–M3 驗的是「手感」，不是數值。
