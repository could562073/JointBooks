饅頭記帳 隱私權政策

生效日期：2026 年 9 月 18 日

這是什麼

饅頭記帳是給兩個人一起用的記帳 App。帳本存在建立者自己的 Google 雲端硬碟裡的一份 Google 試算表， App 沒有自己的資料庫，也沒有廣告或使用行為追蹤。

會存取哪些 Google 資料

  • Google 試算表（spreadsheets）：讀寫帳本那一份試算表，包含記帳紀錄（金額、分類、備註、日期、誰記的）、分類設定、成員名稱與顏色。 App 只開自己建立的帳本，或你透過邀請連結加入的那一份。
  • 本 App 建立的雲端硬碟檔案（drive.file）：用來建立帳本、找回自己的帳本、 把帳本分享給你邀請的人（以對方的 Google 帳號 email 加為編輯者），以及取消分享。這個權限看不到你雲端硬碟裡的其他檔案。

資料存在哪裡

  • 你的 Google 雲端硬碟：帳本試算表，受你的 Google 帳號保護；被邀請的人有編輯權限。
  • 你的手機或瀏覽器：帳本的本機副本（沒網路時也能記帳）、登入用的通行證與續期憑證、App 設定。這些只存在這台裝置上。
  • 登入端點（架在 Cloudflare Workers）：只在登入和續期時，把授權碼或續期憑證轉交給 Google、再把新的通行證交回 App。 端點不儲存任何資料，也碰不到你的帳本內容。

分享與傳輸

不販售、不出租，也不提供給任何第三方。只有你主動邀請的人看得到你的帳本。所有連線都經過 HTTPS 加密。

Google API 有限使用聲明

饅頭記帳使用及轉移從 Google API 取得的資訊時，將遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

饅頭記帳's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

撤銷授權與刪除資料

  • 撤銷授權：到 Google 帳號 →「安全性」→「與第三方應用程式和服務的連結」，移除本 App。之後 App 就無法再存取你的資料。
  • 刪除帳本：在 Google 雲端硬碟刪除帳本試算表。
  • 停止共用：帳本建立者可以在 App 的「配置」頁移除成員，對方就讀不到這本帳。
  • 清除手機上的資料：刪除主畫面上的 App，或在瀏覽器設定清除這個網站的資料。

政策變更與聯絡方式

這份政策有變更時會更新本頁與上方的生效日期。有任何問題，請到 GitHub 專案頁留言。
